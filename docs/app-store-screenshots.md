# App Store 截图说明（v2.0）

仅 iPhone、仅竖屏。商店页最少拍 **6.9 寸一组**；付费墙另存一张给审核备注。

## 规格

| 用途 | 模拟器 | 像素（竖屏） | 是否必须 |
|---|---|---|---|
| 商店页主图 | iPhone 16 Pro Max / 17 Pro Max | 1320 × 2868（也接受 1290 × 2796） | 必须，1–10 张 |
| 更小机型 | 不必另拍 | Apple 会从 6.9 寸缩放 | 可选 |
| iPad | 不要拍 | App 不支持 iPad | 不要上传 |
| 审核备注 | 与商店页同一机型 | 付费墙完整一屏 | 必须（可不上架） |

- 语言：简体中文（`zh-Hans`）
- 外观：浅色模式（App 已锁定浅色）
- 张数建议：商店页 **6 张**（最多 10）
- 格式：PNG，不要加设备外框、营销大字遮挡界面

模拟器：`File → New Simulator` 选 Pro Max，拍完 `Cmd + S`，文件在桌面。

## 拍摄前准备

1. 商店主图不要用空白首启。首次安装默认是空态（昵称「朋友」、无目标）。要拍主态请二选一：
   - Debug Scheme 增加启动参数 `-seedDemo`（会写入英语 / 马拉松 / 星图等演示数据）
   - 或在 Release 里手动建 3 个进行中目标 + 今日任务（「我的」里不能出现「切换 Pro（调试）」）
2. `-seedDemo` 写入内容：
   - 进行中：系统学习英语、准备半程马拉松、个人星图设计集（刚好 3 个，免费版上限）
   - 已归档：完成 30 天早起挑战
   - 今日三件事：英语精读、核心力量、星图草图
3. 把昵称改成适合展示的中文名（默认「朋友」）。
4. 关掉「今日」页的锁屏小组件引导条（避免第一张像未完成引导）。
5. 状态栏保持干净：无低电、无通话、通知尽量关掉。
6. 付费墙那张要能看到 **真实价格**。模拟器用 Scheme 里的 `Configuration.storekit`；审核备注尽量用沙盒账号拉到的价格。
7. 正式商店截图用 **Release** 时，请手动造数，不要带着 Debug 调试行入镜。

## 商店页 6 张（按上传顺序）

商店第一张决定转化。不要把付费墙放第一张。

### 1. 今日 · 主态

- 打开 **今日**
- 要看到：问候 + 昵称、进度环、今日任务列表、底部五 Tab、右下角 FAB
- 勾选 1 条任务，让进度不是 0（例如精读已完成、另外两条待做）
- 不要空态、不要「全部完成」庆祝态

**这一屏在证明什么：** 每天打开就能做今天的三件事。

### 2. 目标 · 进行中列表

- 打开 **目标**
- 要看到：进行中 3 个目标卡片 + 已归档 1 条（可露出一点即可）
- 字幕示例：共 3 个进行中 · 1 个已归档

**这一屏在证明什么：** 目标有进度、可归档，不是待办清单。

### 3. 目标详情

- 点进「系统学习英语」
- 要看到：阶段（打好词汇基础 / 完成精读训练 / 模拟口语考试）和关联任务
- 不要打开删除、归档确认框

**这一屏在证明什么：** 大目标能拆阶段和任务。

### 4. 专注 · 倒计时进行中

- 打开 **专注**，选番茄钟或已有任务，点开始
- 要看到：圆环倒计时、「专注中」、关联目标名称
- 不要拍权限弹窗；若弹出 Live Activity / 通知授权，先允许再拍
- 可选：同时让灵动岛出现倒计时，但商店图仍以 App 内这一屏为主

**这一屏在证明什么：** 专注计时是真实可用的，不是空壳。

### 5. 数据 · 本周

- 打开 **数据**，周期选 **周**
- 要看到：专注时长、完成任务、完成率、周复盘文案（演示数据里今天有 25 分钟专注）
- 若柱状图偏空，先在专注页完成一段再回来拍

**这一屏在证明什么：** 数据来自真实记录，不是占位。

### 6. 付费墙（商店可选，审核必拍）

- 路径：**我的 → Goalstar Pro**
- 整张必须同时出现：
  - 标题 Goalstar Pro，角标「免费版」
  - 权益：**无限进行中目标**、一次买断、换机可恢复（不要出现「开发中」）
  - **价格**（如 ¥28 或沙盒当地价格）
  - 主按钮「购买终身 Pro · 价格」
  - 「恢复购买」
  - 「查看隐私政策」链接露出即可，不必点进去
- 滚动到按钮完整可见；不要截成半截 Sheet
- 不要进入系统付款弹窗（那是系统 UI，不是 App）

**这一屏在证明什么：** 买断、价格、恢复入口都在，且只卖已上线能力。

若希望商店页更「产品」而少「商业」，商店第 6 张可改拍 **我的** 主页（免费版标签 + 成就：1 个已完成目标），把付费墙只放进审核备注。

## 可选加拍（有余量再传）

| 场景 | 怎么拍 | 备注 |
|---|---|---|
| 主屏 Widget「今日三件事」 | 长按桌面 → 添加 Goalstar 小组件 → 拍主屏 | 不要用系统截图上的编辑模式 |
| 锁屏 / 灵动岛 Live Activity | 专注开始后锁屏幕 | 证明 Live Activity 已声明且可用 |
| 新建目标 | FAB → 新建目标表单，标题已填示例 | 不要拍到免费版超限报错当主图 |

## 不要入镜

- 「切换 Pro（调试）」
- DEBUG 模拟器黄条、Xcode 调试悬浮球
- 空态、报错、网络失败、StoreKit「暂时无法购买」
- 深色模式、横屏、iPad
- 把未上线能力写成卖点的任何界面（当前付费墙已去掉）
- 系统付费弹窗、Apple ID 密码页
- 别人的头像、真实邮件、未脱敏信息
